# DawooLISP

DawooLISP는 토목·CAD 실무에서 반복되는 작업을 빠르고 일관되게 처리하기 위한 통합 LISP 도구 모음입니다. 하나의 배포 파일로 AutoCAD와 ZWCAD 2024를 함께 지원하며 설치, 자동 로드, 메뉴 등록, 업데이트 및 복원 기능을 제공합니다.

## 지원 환경

- AutoCAD 2015~2024 (Windows)
- ZWCAD 2024 (Windows)
- 공용 설치 폴더: `C:\DAWOO\CADLISP`

## 주요 기능

- 토목 도면 작성 및 편집 보조 명령
- 레이어·색상·블록 정리
- 문자·치수·다중지시선 설정
- 거리·축척 계산 및 객체스냅 설정
- 도면 점검·정리·복구
- AutoCAD와 ZWCAD 자동 판별 및 전용 컴파일 파일 로드
- 프로그램 내 자동 업데이트와 이전 버전 복원
- PDF 도움말 및 DawooLISP 메뉴 제공
- 'DEF' 도면설정 초기화
- 'DEFST' 문자 스타일 정리 및 만들기
- 'DEFDIM' 치수 스타일 만들기 (스케일적용)
- 'DEFLA' 토목 표준 레이어 만들기
- 'DEFSC' 주석 축척 만들기
- 'DEFCTB' 토목 플롯 스타일 (선두께) 만들기
- `DWC` 원좌표 복사 및 `DWV` 원좌표 붙여넣기
- `DWDT` 문자 스타일 선택 + 입력

- `DWNUM` 도엽번호 조회, 한 번의 클릭으로 반경 1km 지역별 도엽번호 자동 탐색 및 새 빈 도면 원좌표 결합
- `DWJS` 클릭한 필지의 주소 조회
- `DWCM` 브이월드 연속지적도 SHP를 도면에 삽입
- `DWCMA` 삽입된 지적 경계 안에 지번 문자를 자동 정리

## 설치 방법

1. [최신 릴리스](https://github.com/leecycle/DawooLISP/releases)에서 `DawooLISP.*.zip`을 내려받습니다.
2. ZIP을 완전히 압축 해제합니다.
3. 압축을 푼 폴더에서 `Install.exe`를 실행합니다.
4. 설치가 끝나면 AutoCAD 또는 ZWCAD를 다시 시작합니다.
5. 명령창에서 `DWVER`를 실행해 현재 CAD와 DawooLISP 버전을 확인합니다.
6. `DWHELP`를 실행하면 PDF 도움말이 열립니다.

설치 프로그램은 기존 설정을 지우지 않고 다음 항목을 중복 없이 추가합니다.

- `C:\DAWOO` 및 `C:\DAWOO\CADLISP` 신뢰 경로
- `C:\DAWOO\CADLISP\DawooLISP.lsp` 시작하기 세트
- AutoCAD `acad.pgp` 및 ZWCAD `zwcad.pgp` 단축키
- 현재 CAD에 DawooLISP 메뉴가 없을 때 메뉴 자동 등록

## 브이월드 수치지도·연속지적도 준비

`DWNUM`, `DWJS`, `DWCM`을 사용하려면 브이월드에서 필요한 자료를 내려받아 `C:\브이월드` 아래에 압축 해제합니다. 지역에 따라 폴더 이름이 달라도 DawooLISP가 하위 폴더를 자동으로 검색합니다.

필요한 자료가 없으면 `DWNUM`, `DWJS`, `DWCM`이 설치 폴더의 `설치방법.txt`를 메모장으로 열어 브이월드 다운로드 위치와 폴더 예시를 안내한 뒤 안전하게 종료합니다. 정상적으로 자료가 준비되어 있으면 안내 파일을 열지 않습니다.

### 수치지형도 다운로드 - DWNUM

1. [브이월드](https://www.vworld.kr/)에 접속합니다.
2. **공간정보 다운로드 → 공간정보 다운로드**로 이동합니다.
3. **수치지형도**를 검색합니다.
4. **수치지형도 v1.0(1:5000)**을 선택합니다.
5. 파일명에서 필요한 지역을 조회한 뒤 내려받습니다.
6. 압축을 `C:\브이월드` 아래에 풉니다.

폴더 예시는 다음과 같습니다.

```text
C:\브이월드\1MAP5000_DXF_강원_인제군
```

- 폴더명은 지역에 따라 달라도 괜찮습니다.
- DXF 파일은 내려받은 원래 파일명을 유지합니다.
- `DWNUM`은 `C:\브이월드` 아래에서 `1MAP5000_DXF_`가 포함된 폴더와 하위 DXF를 자동 검색합니다.
- 검색된 도엽을 새 빈 도면에 결합할 때 원래 GRS80 좌표가 유지됩니다.

### 연속지적도 다운로드 - DWJS, DWCM

1. [브이월드](https://www.vworld.kr/)에 접속합니다.
2. **공간정보 다운로드 → 공간정보 다운로드**로 이동합니다.
3. **연속지적도**를 검색합니다.
4. **연속지적도_전국**을 선택합니다.
5. 필요한 지역을 조회한 뒤 내려받습니다.
6. 압축을 `C:\브이월드` 아래에 풉니다.

폴더 예시는 다음과 같습니다.

```text
C:\브이월드\LSMD_CONT_LDREG_강원특별자치도
C:\브이월드\LSMD_CONT_LDREG_강원_인제군
```

- 지역별로 폴더명과 SHP 파일명이 달라도 괜찮습니다.
- `.shp`, `.dbf`, `.shx`, `.prj`, `.cpg` 등 함께 받은 파일을 같은 폴더에 보관합니다.
- `DWJS`는 클릭한 필지의 주소를 조회합니다.
- `DWCM`은 선택한 법정주소의 지적 경계와 지번을 도면에 삽입합니다.
- 일부 자료는 GRS80 중부좌표로 제공되므로 현재 도면에 맞게 서부·중부·동부 원점을 선택합니다.
- 전체 주소 표시에는 설치 폴더의 법정동코드 자료가 사용됩니다.

## AutoCAD와 ZWCAD를 함께 사용하는 경우

두 CAD는 같은 `C:\DAWOO\CADLISP` 설치 폴더를 사용합니다.

- AutoCAD에서는 `DawooLISP_*_AutoCAD.VLX`를 자동으로 불러옵니다.
- ZWCAD 2024에서는 `DawooLISP_*_ZWCAD.zelx`를 자동으로 불러옵니다.
- 메뉴 등록 상태는 AutoCAD와 ZWCAD에서 각각 확인하며, 없는 경우에만 자동 등록합니다.
- 한 번 업데이트하면 AutoCAD용과 ZWCAD용 파일이 함께 교체됩니다.
- 모든 도구막대 아이콘은 `C:/DAWOO/CADLISP/Icons/`의 PNG 절대경로를 사용합니다.

## 업데이트

`DWOP` 5번에서 정식버전 또는 베타버전 업데이트 채널을 선택하고 저장할 수 있습니다. 선택값은 사용자 설정 폴더에 보존됩니다.


1. CAD 명령창에서 `DWUPDATE`를 실행합니다.
2. 설정한 업데이트 채널에 따라 GitHub의 최신 정식 또는 공개베타 릴리스를 비교합니다.
3. 업데이트를 승인한 뒤 도면을 저장합니다.
4. AutoCAD와 ZWCAD를 모두 완전히 종료합니다.
5. 기존 설치 폴더 전체를 백업하고 새 패키지를 검증한 뒤 교체합니다.
6. 실패하면 전체 백업을 자동으로 복원합니다.

업데이트는 기존 신뢰 위치, 시작하기 세트, PGP 단축키 및 다른 작업공간을 변경하지 않습니다. 인터넷 연결 오류 안내는 `DWUPDATE`를 실행했을 때만 표시됩니다.

## 메뉴와 도움말

- `DWTOOLBAR`: DawooLISP 도구막대 표시
- `DWHELP`: PDF 도움말 열기
- `DWUPDATE`: 최신 버전 확인 및 업데이트
- `DWROLLBACK`: 백업된 이전 버전으로 복원
- `DWOP`: 설치 폴더·백업·버전·재로드·업데이트 채널 설정

전체 명령과 사용 방법은 설치 폴더의 `DawooLISP_Help.pdf`에서 확인할 수 있습니다.

## 주의 사항

- AutoCAD와 ZWCAD가 실행 중일 때 설치 파일을 강제로 교체하지 마십시오.
- LISP 원본은 ANSI(CP949) 인코딩을 유지합니다.
- 배포 ZIP에는 AutoCAD용 VLX와 ZWCAD용 ZELX가 모두 포함되어야 합니다.
- 문제가 생기면 CAD를 종료한 뒤 마스터 설치본으로 다시 설치하거나 `DWROLLBACK`을 사용하십시오.

## 1.7.0 정식버전

- 문자·레이어 명령을 DW 체계로 통일했습니다: `DWDT`, `DWQ`, `DWQ1`, `DWW`, `DWLI`, `DWBYL`, `DWBYB`.
- 축척·도구 명령을 DW 체계로 통일했습니다: `DWHTC`, `DWSCL`, `DWSSS`.
- 도면 점검 명령을 DW 체계로 통일했습니다: `DWPP`, `DWAUD`, `DWCL`, `DWDWG`, `DWRECOV`.
- 전문 도구 명령을 DW 체계로 통일했습니다: `DWNO`, `DWJ`, `DWBN`, `DWWMF`, `DWC`, `DWV`.
- `QS`와 `REA`는 제거했으며 CAD 기본 `QSAVE`와 `REGENALL`을 사용합니다.
- DWMAP과 DWJB는 TM 위치를 기준으로 도면 좌표계를 판정하고 추천 좌표계와 변환 경도를 표시합니다.
- 설치·업데이트·신뢰 위치·시작세트·PGP·메뉴 등록 방식은 검증된 기존 구조를 유지합니다.
