## DawooLISP 1.6.0 정식버전

DawooLISP 1.5.0 정식버전 이후 1.5.1~1.5.13 공개베타에서 검증한 기능 추가와 개선 사항을 통합한 정식버전입니다.

### 수치지도·연속지적도

- `DWMAP` 추가: 지정한 중심점과 반경에 포함되는 국토지리정보원 1:5,000 수치지도 도엽번호 검색
- GRS80 서부·중부·동부 원점 선택, 검색 반경 원과 도엽번호 다중문자 작성 지원
- `C:\브이월드` 아래의 지역별 수치지도 DXF를 자동 검색하고 새 빈 도면에 원래 GRS80 좌표로 결합
- 일부 DXF가 없을 때 발견한 도엽만 결합하고 누락 도엽번호 안내
- `DWJB` 추가: 클릭한 필지의 지번·전체 법정동 주소·PNU 조회
- `C:\브이월드` 아래의 `LSMD_CONT_LDREG*.shp`를 하위 폴더까지 자동 검색
- GRS80 서부·중부·동부 도면 좌표를 연속지적도 중부원점 좌표로 변환
- DBF의 `JIBUN`을 우선 사용하여 `349-6`, `산 12-3` 형식으로 표시
- SHP 폐합점의 0길이 선분으로 인한 필지 오인 판정 수정
- 조회 주소를 현재 문자 스타일의 다중지시선으로 작성하고 문자 폭 자동 조정
- 법정동코드 전체자료를 설치 패키지에 포함하고 관련 데이터 다운로드 방법을 PDF 도움말에 추가

### 문자·문자 스타일

- `DEFST`에서 돋움체 표준 문자 스타일 생성 및 기존 TEXT·MTEXT·치수·다중지시선 정리
- 문자 높이 10·7·5·4·3·2를 주제목·부제목·보조제목·소제목·일반문자3·일반문자2에 대응
- 일치하는 고정 높이가 없으면 `일반문자` 스타일을 적용하고 원래 내용·높이·위치·회전·형상을 유지
- `일반문자` 스타일의 고정 높이는 0으로 유지하고 `DT`·`TEXT` 기본 높이를 2.5로 설정
- `DDT` 추가: 표준 문자 스타일 또는 기본 일반문자를 선택하여 바로 입력
- DEFST 완료 후 문자 입력을 시작하지 않고 결과만 출력한 뒤 종료

### 주석 축척·측점

- `DEFSC` 추가: 현재 도면에 `1 : 100`, `1 : 1000`, `1 : 3000` 기본 주석 축척 자동 추가
- 사용자가 입력한 축척을 용지 단위 1 기준으로 생성하고 같은 이름은 중복 생성하지 않음
- 현재 축척과 사용 중인 축척을 제외한 미사용 주석 축척을 실행 시작 시 정리
- AutoCAD·ZWCAD의 공식 `-SCALELISTEDIT` 방식을 사용하고 내부 진행 과정은 숨겨 결과만 간결하게 출력
- `DNO`에서 선형을 클릭한 쪽과 가까운 끝점을 시점으로 자동 결정
- 20m 간격은 눈금, 100m 간격과 종점은 원형 측점 및 문자로 표시
- `STA 0+000`, `STA 0+100`, `STA 0+135` 및 `NO 0+0`, `NO 5+0`, `NO 6+15` 형식 적용
- 정수 측점값의 불필요한 소수점을 제거하고 문자 방향을 왼쪽 또는 오른쪽으로 선택 가능

### 명령·메뉴·도구막대

- `BCC`를 `CCC`, `BVV`를 `VVV`로 변경하고 이전 명령 제거
- 도구막대 순서를 `DNO → DDT → JJ → OSDEF → OSED`로 정리
- `DEFSC`를 `DEFLA` 다음, `DWMAP`·`DWJB`를 전문 도구 영역에 배치
- 도구막대에서는 표시·다시 등록 버튼을 제거하고 메뉴막대에는 유지
- 메뉴 그룹을 시작할 때 반복 언로드하지 않고 메뉴가 없을 때만 로드하도록 변경
- `DWTOOLBARREPAIR` 실행 시에만 도구막대를 수동 재등록하여 사용자가 지정한 위치 유지
- 모든 도구막대·메뉴막대 아이콘을 `C:/DAWOO/CADLISP/Icons/` PNG 절대경로로 연결

### 아이콘 정리

- 모든 아이콘에 32×32 큰 아이콘과 16×16 작은 아이콘 제공
- 롤백·업데이트·환경설정·도움말·도구막대 관련 아이콘을 공통 배경과 흰색 도형 스타일로 통일
- DEF~DEFCTB는 형광 파랑, DNO·DDT·JJ는 형광 노랑으로 통일
- OSDEF·OSED는 형광 하늘색, DWMAP·DWJB·H2TC·MWMF는 형광 녹색으로 통일
- DWMAP·DWJB 작은 아이콘을 16×16 크기에 맞게 별도 최적화

### 설치·업데이트 호환성

- AutoCAD와 ZWCAD 2024용 컴파일 파일을 하나의 설치 파일로 통합 배포
- 신규 설치에서만 신뢰 위치·시작세트·PGP·메뉴 등록을 처리
- 업데이트에서는 기존 PGP·신뢰 위치·시작세트를 유지하고 필요한 프로그램 파일만 교체
- 기존 명령, 백업·롤백, 업데이트 채널, 설치 폴더 구조와 사용자 설정 유지

### 설치 방법

1. 배포 ZIP을 완전히 압축 해제합니다.
2. AutoCAD와 ZWCAD를 모두 종료합니다.
3. `Install.exe`를 실행합니다.
4. 설치 후 CAD를 다시 실행하고 `DWVER`로 버전을 확인합니다.
