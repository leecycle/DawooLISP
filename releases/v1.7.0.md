# DawooLISP 1.7.0 정식버전

DawooLISP 1.6.0 정식버전 이후 1.6.1~1.6.4 공개베타에서 검증한 개선 사항을 통합한 정식버전입니다.

## 주요 변경 사항

- **플롯스타일·WMF**: DEFCTB 세트1~세트4의 출력색·선가중치를 사용자 기준 CTB로 교체하고, DWWMF가 배치 MSPACE에서도 정상 복사되도록 개선했습니다.
- **환경설정**: DWOP 업데이트 채널 저장 방식을 통일하고 전체 VLX/ZELX 로드 후 기존 정의가 덮어쓰던 문제를 수정했습니다.
- **기능 분리**: DWATEX, DWATIM, DWMAPALI를 DawooCivilLISP로 이동하고 DawooLISP 관련 항목을 정리했습니다.
- **좌표계 자동 판정**: DWMAP·DWJB가 클릭한 TM 위치를 SHP 실제 필지와 대조하여 서부·중부·동부원점을 추천합니다.
- **명령 체계 통일**: 문자·레이어·축척·점검·전문 도구 명령을 DW 접두어로 통일하고 QS·REA는 CAD 기본 QSAVE·REGENALL로 대체했습니다.
- **설치·업데이트 유지**: 1.6.4에서 검증한 신규 설치, 업데이트, 신뢰 위치, 시작세트, PGP, 메뉴 등록 방식을 그대로 유지했습니다.

## 설치

1. 배포 ZIP을 완전히 압축 해제합니다.
2. AutoCAD와 ZWCAD를 모두 종료합니다.
3. Install.exe를 실행합니다.
4. CAD 재시작 후 DWVER에서 1.7.0을 확인합니다.
